# BASTILLE — le jeu

Jeu satirique de la manif République–Bastille (HTML5, mobile d'abord).

- `index.html` : le jeu
- `admin.html` : tableau de bord (connexion Supabase, réservé aux e-mails de la table `admins`)
- `confidentialite.html` : politique de confidentialité
- `config.js` : URL et clé **anon public** Supabase, adresse de contact
- `track.js` : statistiques anonymes et inscription e-mail
- `supabase/schema.sql` : tables et règles de sécurité à exécuter dans Supabase
